 Accept plan type (monthly | yearly)

 Attach correct Stripe price_id

 Set mode=subscription

 Attach authenticated user ID to metadata

 Create or reuse Stripe Customer

 Return checkout_url to frontend

 Frontend opens Stripe Checkout

 Handle user cancellation safely

 Fields:

user_id

stripe_subscription_id

stripe_price_id

status (trialing | active | past_due | canceled)

current_period_end

 Link subscription to user record

 Prevent duplicate subscriptions

checkout.session.completed

customer.subscription.deleted

 Update subscription status on webhook

 Log webhook failures

 Idempotency protection
